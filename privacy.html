1. Overview

Baupunkt is designed as a local-first app for construction site documentation, defect tracking, responsibilities, project files and reports.

2. Local-first storage

Baupunkt stores project data locally on the device. Photos, documents and project information remain local unless users export, save or share them themselves.

3. No user accounts

The app does not use Baupunkt user accounts. There is no Baupunkt login, account profile or account-based cloud storage in the current product model.

4. No cloud synchronization

Baupunkt does not synchronize project data with a Baupunkt server. If users save project files to services such as iCloud Drive, Google Drive or another storage provider, that action is controlled by the user and subject to the terms and privacy practices of that provider.

5. No tracking, analytics or advertising

The app does not include tracking, analytics or advertising SDKs. The website does not include tracking scripts, analytics scripts, cookies or external fonts.

6. Camera and photos

Camera and photo access are used only when users choose to capture or add photos for defect documentation or construction site documentation. Baupunkt does not use photos for OCR, AI analysis, advertising or tracking.

7. Project files and exports

Project files, reports and backups are created, saved or shared by explicit user action. A project file is intended as a complete project backup including local photos and documents. Reports are exports for review or sharing and are not a replacement for a full project file.

8. Data sharing

Baupunkt does not send project data to a Baupunkt server. Users may choose to share project files, reports, photos or documents through operating-system sharing features or third-party storage services. Those actions are initiated by the user.

9. Website hosting

This website is hosted with GitHub Pages. When visiting the website, technical server data may be processed by GitHub as the hosting provider. Baupunkt does not add its own analytics or tracking tools to this website.

10. User control and deletion

Users can delete app data by deleting local app data, browser data, project files or exported backups from their device or chosen storage location. Before deleting data, users should create a project file if they need to keep a backup.

11. Contact

For privacy or support questions, contact: burkipatrick@outlook.com.
