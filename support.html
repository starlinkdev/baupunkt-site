Support

1. What is Baupunkt?

Baupunkt is a local-first app for construction site documentation, defect tracking, responsibilities, documents, photos and reports.

2. Getting started

Start by creating a project. Add basic project information, then record defects, assign responsibilities and export reports when needed.

3. Create a project

Use the onboarding or project area to create a local project. Project data is stored on the device until you export or delete it.

4. Record a defect with photo

Use the capture area to create a defect, add a title, location, priority and photo. Photos are used for defect documentation.

5. Review defects

Use the review area to check new defects, add missing information, assign contractors or responsibilities and mark items as reviewed or completed.

6. Export reports

Reports are files for review, communication or sharing. They summarize project information but are not a complete backup of the project.

7. Save a project file

A project file is a complete backup including project data, photos and documents. Save a project file after important changes, after mobile capture sessions and before restoring older data.

8. Restore a project file

Restoring a project file loads a saved project state. Review the import preview carefully before confirming a restore.

9. Mobile handoff

Baupunkt does not automatically synchronize devices. To move data between devices, create a project file or handoff file and transfer it manually, for example through operating-system sharing or file storage chosen by the user.

10. Troubleshooting

I cannot find my project data

Baupunkt stores data locally. Check whether you are using the same device, browser or installed app where the project was created. If you moved devices, restore the latest project file.

A photo is missing

Photos are stored locally and included in complete project files. If a photo is missing, restore from a project file that was created after the photo was added.

I do not see changes from another device

There is no automatic sync between devices. Export a project file or mobile handoff from the source device and import it on the target device.

What is a project file?

A project file is the complete project backup. It is intended to include project data, photos and documents.

What is the difference between a report and a project file?

A report is an export for review or sharing. A project file is the full backup used to preserve or restore a project.
